Goal of this project: Fast win/osx app that enables DJs to analyze, organize, and prepare their music files.

Similar to: Mixed in Key, Songfinder, beaTunes
Better Because:
    - Stable
    - Fast
    - Highly Accurate in detecting a song's bpm and key
    - Able to build playlists based on harmonic relationships of the music using Camelot wheel techniques. (Examples include doing a +2 on the camelot wheel for an energy boost in a set. There are other examples and guides with simimlar formulas or "rules of thumb", to build DJ sets)
    - 
    The goal is for the human to be Able to build dynamic, 
    
    Must work with all major audio files (especially .mp3, .wav, .flac, .ogg, .aiff, .m4a, .mp4)

^ This site would play the song and you would be able to visually see what other songs were being played as part of a djs mashup set. I want to incorporate this kind of visual element into the app. It needs to be more than just a list of songs, it needs to be a visual representation of how songs are related to each other.  The user should also be able to mix two songs at the same time similar to dj software like traktor or serato. However, this is purpose kept basically and only offers playback, volume control (mixer), crossfader, eq control (knobs and kill switch), and a simple waveform visualization.
